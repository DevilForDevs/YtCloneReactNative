# ✨ Features

### 🎬 Media Playback
• Built-in video player  
• Shorts-style vertical player  
• Offline media player  

### 🔎 Content Browsing
• Endless browsing & search  
• Nested FlatLists for fast UI rendering  

### 📰 E-Paper Viewer
Supports viewing newspapers(subscription bypass) such as:

- **Times of India**
- **Prabhat Khabar**
- **Dainik Jagran**

The app provides an optimized reader experience for viewing daily epapers directly within the app.

### ⚙️ Architecture
• **React Native**  
• **Zustand** state management  
• **SQLite storage** for offline data  
• **Custom media pipeline**

---

# ⚠️ Policy Update

Due to **Google Play Store policies**, the following functionality has been removed from the Play Store version:

- ❌ YouTube video downloading  
- ❌ Media extraction for downloading  

The current version of the app focuses on:

✔ Media playback  
✔ News & epaper viewing  
✔ Content browsing
